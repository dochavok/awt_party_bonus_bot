# Glossary

**Allies**
:   Everyone who can receive a bonus, except the character giving it.

**Audience**
:   Who can receive a bonus: the whole party, only members of one guild, or only other
    holders of the same entry.

**Catalog**
:   The fixed list of every skill, guild, rank, boon, item and title that gives a party
    bonus. `/catalog` shows it. Missing something? Use `/request`.

**CM**
:   Combat modifier: attack and defence combined.

**Combat notes**
:   Bonuses measured in hearts: damage, damage reduction and healing.

**Conditional bonus**
:   A bonus that only applies in a situation the bot can't see, such as "allies in the
    same range". Listed separately and never in the totals.

**Counted**
:   In the voice channel and not sitting out.

**CR**
:   Challenge roll. The kinds of CR (*vs fear*, *stealth*, *escape*, *would hurt*) each
    include the plain CR bonus.

**Current character**
:   The character you're playing, chosen with `/play`. Commands use it when you don't
    name a character.

**Effect**
:   A benefit with no number, such as resistance to damage from an Evil source.

**Entry**
:   Anything in the catalog a character can have: a skill, boon, rank, item or title.

**Giver**
:   The character who provides a bonus.

**Guild**
:   Any group a character can belong to: a guild, order, cult or coalition. Joining
    records membership; the bonuses come from ranks and boons.

**Modifier**
:   An entry that changes the same character's other bonuses instead of giving one
    itself, such as Devotion III.

**Party**
:   Everyone counted in the voice channel.

**Rank**
:   A guild rank that gives one or more abilities, added with `/add` like a skill. A
    higher rank replaces the lower ones.

**Replaces**
:   When a character has an entry and a better version of it, only the better one
    counts.

**Secret guild**
:   A guild whose members the bot never reveals: the Guild of Thieves.

**Sitting out**
:   Not counted for 12 hours, after `/sitout`. For the DM running the game and anyone
    just watching.

**Stacks / doesn't stack**
:   A bonus that stacks counts once per giver. One that doesn't stack counts once,
    however many givers are present.

**Support**
:   +2 CM to allies from each player with a Guild rank role (Junior Adventurer or
    above). Comes from the Discord role; there's nothing to add.
